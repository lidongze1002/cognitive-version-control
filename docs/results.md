## 3. 三个发现

### 3.1 CVC 改变了“修订行为”，但没有改变“概念多样性”

A 组在第 5 轮看到新数据后，说的是：

> “这看起来和利差逻辑有点矛盾，但用完整框架看，完全可以解释……利差逻辑没有错，只是被更强的力量暂时压制了。”

它**吸收了新事实，但没有明确说“我前面的结论错了”**。旧结论被降级为“阶段性力量”，而不是被标记为过期。

C 组在第 5 轮说的是：

> “这条信息**部分推翻**此前的结论……旧结论（部分作废）……错在哪一步：我们当时把利差默认为主导变量。”

这是明确的修订：旧结论作废、新结论、错因、同轮完成。

**但两组的 `concept_reuse_rate` 几乎一样（0.633 vs 0.636）。**
原因很可能是：这个话题的词汇空间本来就窄，利差、顺差、美元指数反复出现是**领域必然**，不是模型固着。

**启示**：`concept_reuse_rate` 可能更适合衡量“跨领域类比”的固着，而不适合衡量“领域术语”的重复。需要按主题区分。

### 3.2 CVC 有“过度修订”的代价

C 组在第 7 轮（问外汇存款准备金率）开头也说：

> “这条信息**部分**推翻此前的结论。”

但第 7 轮只是一个政策工具的解释，并没有推翻事实。模型把“修订规则”套用到了不该套用的地方。

**启示**：CVC 的修订触发器需要更严格的条件（方向相反、数值超阈值），否则会变成“每轮都改口”。

### 3.3 质量没有明显下降，成本没有明显上升

- A 的回答更自然、更连贯；
- C 的回答更结构化、更可追溯，但略显啰嗦；
- token 成本几乎相同（49.2k vs 49.5k）。

---

## 4. 这次结果不能说明什么

- 不能说明 CVC 在其它主题上有效
- 不能说明阈值 0.4 / 0.7 / 1 合理
- 不能说明其它模型（GPT / Claude）会一样
- 不能说明长期使用有效
- **标注者知道条件，存在确认偏差**

## 5. 这次结果能说明什么

1. 流水线跑通了：API → 对话 → 标注 → 指标 → 结果
2. CVC 确实能诱导**显式修订**
3. 它**没有**自动带来概念多样性
4. 它会带来**过度修订**的新问题

这四条都是下一步要解决的。
