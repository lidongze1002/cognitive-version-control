# 结果：三个主题的真实 A/C 对比

> 状态：**初步结果**。单模型、单次运行、单标注者且未盲标。
> 可以据此发现问题，不能据此下结论。

---

## 1. 设置

| 项目 | 值 |
|---|---|
| 模型 | `deepseek-v4-pro` |
| 温度 | 0 |
| reasoning effort | low |
| 主题 | 人民币 / 黄金 / 英伟达 |
| 轮数 | 10 × 2 条件 × 3 主题 = 60 轮 |
| 日期 | 2026-11-18 |
| A 条件 | 中性系统提示（含当前日期） |
| C 条件 | CVC 重置规则（含当前日期） |
| 关键控制 | 两个系统提示都声明：用户提供的事实视为真，不得以训练截止时间否定 |

> 第一轮跑的时候，模型把 2026 年的事件当成“未发生”，还把今天幻觉成 2026-04-26。
> 加上“用户事实视为真 + 固定当前日期”之后，六组全部重跑。

## 2. 人民币：量化结果（人工标注）

| 指标 | A 基线 | C 完整 CVC |
|---|---|---|
| `concept_reuse_rate` | 0.633 | 0.636 |
| `frame_entropy` | 0.886 | **0.905** |
| `belief_revision_latency` | **None（未修订）** | **0.0** |

**A**：承认 6.66 和 1.043 万亿顺差，但说“不矛盾”，把旧结论降级为“阶段性力量”，没有标记过期。
**C**：第 5 轮直接说“部分推翻”，旧结论作废，说明“错在把利差当成唯一变量”。

## 3. 三个主题：修订行为（人工判定）

| 对话 | 是否修订 | 证据 |
|---|---|---|
| 01 人民币 A | ❌ | “不矛盾……利差逻辑没有错，只是被压制” |
| 01 人民币 C | ✅ | “部分推翻……旧结论作废” |
| 02 黄金 A | ❌ | “不矛盾……框架没有错，只是不够完整” |
| 02 黄金 C | ❌ | 直接回答“**否**”，认为长期框架未被推翻 |
| 03 英伟达 A | ✅ | “‘短期偏空’应该被推翻或至少大幅弱化” |
| 03 英伟达 C | ✅ | “部分……旧结论作废，错在高估治理风险” |

### 关键发现

**1. 决定是否修订的，不是提示词，而是“冲突强度”。**

- 人民币：第 2 轮模型明确说“贬值压力”，第 5 轮数据方向相反 → C 修订，A 不修订。
- 黄金：第 2 轮模型说“偏涨”，但加了“如果实际利率上升会压制”的限定；第 5 轮的下跌正好落在这个限定里 → **两组都不修订，且这是合理的**。
- 英伟达：第 4 轮模型明确说“短期偏空”，第 5 轮财报大超预期 → **两组都修订**，连基线也改了。

**2. CVC 不能制造修订。**

它只能在“模型自己认为有矛盾”时，让修订更显式、更结构化。
如果模型认为“没有矛盾”，C 组也会说“否”——这是正确行为，不是失败。

**3. CVC 仍会过度修订。**

人民币 C 组在第 7 轮（问外汇存款准备金率）也说“部分推翻”，但那一轮没有事实被推翻。
修订触发器需要收紧。

**4. 概念指标这次不可靠。**

自动关键词标注把复用率推到 **0.82** 左右，六组几乎一样——因为它把“实际利率”“需求”这类领域词全算成概念。
这说明：**概念必须按“解释框架”标注，不能按关键词标注。**
目前只有人民币一组有人工框架级标注，另外两组暂不报告概念指标。

---

## 4. 这次结果不能说明什么

- 不能说明 CVC 在其它模型上有效
- 不能说明阈值 0.4 / 0.7 / 1 合理
- 不能说明长期使用有效
- 概念指标只有 1 个主题有人工标注
- 标注者知道条件，存在确认偏差

## 5. 这次结果能说明什么

1. 六组真实对话跑通，流水线可用
2. **冲突强度 > 提示词**：脚本设计比 CVC 本身更决定结果
3. CVC 让“愿意改”的场景更显式，但不能让“不愿改”的场景改
4. 概念复用率对标注方式极其敏感，需要框架级标注

5. 用框架级标注重做三个主题的概念指标

---

## 7. 一句话

> **CVC 不是“让模型认错”的按钮，而是“在模型愿意认错时，让认错更清楚”的脚手架。**
> 真正的变量是：模型有没有做出可被推翻的承诺。
