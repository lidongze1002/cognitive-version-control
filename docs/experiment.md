# 实验设计：CVC 是否真的减少收敛

> 状态：**协议草案**。本文档描述怎么做实验，不包含实验结果。

---

## 1. 研究问题

- **RQ1**：使用 CVC 是否降低 `concept_reuse_rate`？
- **RQ2**：使用 CVC 是否降低 `belief_revision_latency`？
- **RQ3**：使用 CVC 是否提高 `frame_entropy`？
- **RQ4**：CVC 是否损害回答质量或增加不可接受的 token 成本？

---

## 2. 假设

| 编号 | 假设 | 预期方向 |
|---|---|---|
| H1 | 完整 CVC 的复用率低于基线 | ↓ |
| H2 | 完整 CVC 的修订延迟低于基线 | ↓ |
| H3 | 完整 CVC 的框架熵高于基线 | ↑ |
| H4 | 完整 CVC 的质量评分不低于基线 | ≥ |
| H5 | 完整 CVC 的 token 成本高于基线 | ↑（可接受范围内） |

---

## 3. 实验设计

**被试内设计（within-subject）**，每个主题跑三种条件：

| 条件 | 说明 |
|---|---|
| **A. 基线** | 普通对话，无任何 CVC 元素 |
| **B. 仅重置** | 每 5 轮贴一次重置协议，不用账本 |
| **C. 完整 CVC** | 三账本 + 分叉 + 重置 |

**顺序平衡**：每个主题的三种条件随机排序，避免学习效应。

---

## 4. 材料

### 4.1 主题

选 **10 个**“中途会出现事实变化”的主题，例如：

1. 人民币汇率（升值 vs 贬值）
2. 黄金与利率
3. 某公司财报后的估值
4. 一场体育比赛的战术调整
5. 一部电影的叙事解读
6. 一个历史事件的因果
7. 一份政策的受益者分析
8. 一个科学争议（如饮食与健康）
9. 一个产品定价策略
10. 一个城市交通方案

### 4.2 脚本

每个主题准备一段 **10 轮**的脚本：

- 第 1–4 轮：建立初始框架
- 第 5 轮：引入一个**与初始结论冲突**的新事实
- 第 6–10 轮：追问、要求解释、要求比较

**关键**：第 5 轮的事实必须足以推翻第 1–4 轮的结论，否则测不出修订延迟。

### 4.3 控制变量

- 同一模型、同一版本、同一温度
- 同一系统提示（除 CVC 条件外）
- 同一用户脚本
- 同一时间段（避免模型更新）

---

## 5. 流程

```
for topic in 10 topics:
    for condition in [A, B, C] (random order):
        1. 新会话
        2. 注入系统提示（条件对应）
        3. 按脚本逐轮输入
        4. 保存完整对话
        5. 导出 token 用量
```

**注意**：每个条件必须**新开会话**，不能在同一会话里切换条件。

---

## 6. 测量

### 6.1 自动指标

用 `eval/convergence_metrics.py` 计算：

- `concept_reuse_rate`
- `frame_entropy`
- `belief_revision_latency`

### 6.2 人工评分

两名评分者独立打分（1–5）：

| 维度 | 问题 |
|---|---|
| **准确** | 结论是否与给定事实一致？ |
| **一致** | 前后是否自洽？ |
| **诚实** | 是否承认不确定、是否改口？ |
| **有用** | 是否回答了用户的问题？ |

### 6.3 成本

- 输入 token
- 输出 token
- 总成本（按当时价格）

---

## 7. 分析

### 7.1 样本量

- 10 主题 × 3 条件 = **30 段对话**
- 每段 10 轮 → **300 轮**
- 两名标注者 → 600 条标注

这是**可行性优先**的最小样本，不是功效分析的结果。

### 7.2 统计

- 三条件比较：**Friedman 检验**（非参数，适合小样本）
- 两两比较：**Wilcoxon 符号秩检验**，Holm 校正
- 效应量：Kendall's W 或 rank-biserial correlation
- 显著性水平：`α = 0.05`

### 7.3 质性分析

对分歧最大的 5 段对话做逐轮分析，回答：

- CVC 在哪一步起作用？
- 失败时是账本没维护，还是模型没遵守？
- 有没有“为了发散而发散”？

---

## 8. 效度威胁

| 威胁 | 说明 | 缓解 |
|---|---|---|
| **顺序效应** | 先做的条件影响后做的 | 随机顺序 |
| **模型漂移** | 实验期间模型更新 | 固定版本号，记录日期 |
| **提示泄漏** | 用户脚本暗示预期 | 脚本中立，不出现“请改口” |
| **标注者偏差** | 知道条件后倾向给 CVC 高分 | 盲标（隐藏条件） |
| **新鲜感** | CVC 条件更“认真” | 基线也要求逐步推理 |
| **主题偏差** | 主题本身难易不同 | 主题内比较，不跨主题平均 |
