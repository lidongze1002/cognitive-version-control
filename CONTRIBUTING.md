# Contributing

Thanks for taking a look. This project is a draft and feedback is welcome.

## Ways to contribute

- **Counterexamples**: conversations where CVC made things worse
- **Prior art**: papers or tools we missed (please include links)
- **Metrics**: better operationalizations of convergence
- **Prompt variants**: for different models or languages
- **Case studies**: anonymized transcripts with before/after

## Ground rules

1. **No overclaiming.** If you add a claim of novelty, include a prior-art
   search and cite what you found.
2. **Facts need sources.** Any factual claim in docs or examples must include
   a source and a date.
3. **Keep it model-agnostic.** Avoid vendor-specific features in the core spec.
4. **Small PRs.** One change per pull request.

## Issue template

```text
Type: bug | prior-art | metric | prompt | case-study
What happened:
What you expected:
Minimal example:
Model / version:
```
