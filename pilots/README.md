# ⚠️ SIMULATED DATA — NOT EVIDENCE

Everything in this directory was **generated by the author acting as both the
user and the assistant**, for the sole purpose of testing the pipeline
(scripts → transcripts → annotations → metrics).

It is **not** an experiment:

- the same model wrote both conditions,
- the author knew the hypothesis,
- the "baseline" was written to fail and the "CVC" run was written to succeed.

**Do not cite these numbers as evidence.** They are useful only to find bugs
in the tooling. The real experiment is described in
[`../docs/experiment.md`](../docs/experiment.md) and must be run against
independent model sessions.

## What is here

```text
pilots/01-rmb/
├── A.jsonl              # baseline transcript (6 turns)
├── C.jsonl              # CVC transcript (6 turns)
├── A.annotation.json    # annotation for A
└── C.annotation.json    # annotation for C
```

## Why it exists

The pilot exposed two bugs in the metrics:

1. the revision clock started when the **old** belief appeared, not when the
   **contradicting fact** arrived;
2. never revising was scored as neutral (0.5), which rewarded stubbornness.

Both were fixed in v0.2.2. See [`../docs/pilot-results.md`](../docs/pilot-results.md).
